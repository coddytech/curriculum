# HTML & CSS Journey

HTML and CSS are how the web is built: structure first, then styling, layout and your first real front-end pages. The journey takes you from your first tag to interactive pages with JavaScript.

**[Start the HTML & CSS journey →](https://coddy.tech/landing/html)**

At ~30 minutes a day, most people finish in 4–8 weeks. 241 lessons across 5 sections. Finish every section to earn the free certificate.
