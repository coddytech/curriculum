# Computer Networking

Learn networking hands-on in a terminal lab: no slides, just hosts, switches, routers and the commands that make them talk. Every course earns a free certificate.

Pairs naturally with the [Terminal journey](../journeys/terminal.md).

Browse the full topic on Coddy: [Computer Networking Courses](https://coddy.tech/landing/topic/computer-networking-courses)

## The track, in order

Concepts → addressing → terminal tools → building real networks.

1. [The OSI Model](https://coddy.tech/landing/courses/the_osi_model) 🎓 — 32 lessons. The mental model for everything that follows: what each layer does and how data actually moves.
2. [IP Addressing and Subnetting](https://coddy.tech/landing/courses/ip_addressing_and_subnetting) 🎓 — 46 lessons. IPv4 addresses, masks, CIDR and carving up networks — the layer-3 skills the labs depend on.
3. [Networking with the Terminal](https://coddy.tech/landing/courses/networking_with_the_terminal) 🎓 — 47 lessons. DNS, ports and sockets, reachability checks, and HTTP and HTTPS by hand with curl.
4. [LAN Labs](https://coddy.tech/landing/courses/lan_labs) 🔥 🎓 — 35 lessons. Build, address and troubleshoot small networks: ARP, gateways, routing tables and the classic faults that break real LANs.
